# odin-recipes
First Project on The Odin Project. Covers basics of HTML.

In TOP's curriculum, this project is the first one you encounter after you finish learning the basics of HTML. The objective is to build a website called "Odin Recipes" to display recipes and other related content about it in a structured manner.

It covers basic topics such as making a basic webpage using HTML, setting up titles, headings, explanation about some boilerplate code, commonly used HTML tags, lists, attaching images and links to resources (both local and those on the web).
